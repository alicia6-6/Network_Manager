IPv4 헤더와 IPv6

  • IPv4: 32비트, 헤더 가변 20~60바이트, Header Checksum 존재, 라우터도 단편화 가능
  • TTL: 라우터를 지날 때마다 1 감소. 0이면 폐기하고 ICMP Time Exceeded 전송
  • IPv6: 128비트, 16진수 8그룹, 기본 헤더 40바이트, 브로드캐스트 없음
  • IPv6는 송신 호스트만 단편화하며 Fragment 확장 헤더를 사용. Header Checksum 없음
  • ::1 Loopback, FE80::/10 Link-local, FF00::/8 Multicast
  • 전환 기술: Dual Stack, Tunneling, Translation(NAT64 등)

전송·오류 제어·토폴로지

전송 방식

단방향

한 방향만. 방송, 키보드→컴퓨터

반이중

양방향이지만 동시 불가. 무전기

전이중

양방향 동시. 전화

  • 동기식: 문자 사이 휴지 없음, 블록 단위, 효율 높음 / 비동기식: Start·Stop bit, 문자 단위
  • 회선 교환: 전용 경로, 일정 지연, 설정 시간 필요 / 패킷 교환: 회선 공유, 저장 후 전달, 지연 변동
  • 다중화: FDM 주파수, TDM 시간, WDM 광 파장, CDM 코드로 채널 분리
  • 감쇠: 거리가 멀수록 세기 감소 / 왜곡: 주파수별 전달 차이 / 잡음: 원치 않는 신호

Active Directory

  • Domain: 공통 DB·정책·인증을 공유하는 관리 단위
  • OU: 한 도메인 안에서 부서별로 객체를 묶고 GPO·관리 권한을 위임하는 단위
  • Tree: 연속된 DNS 이름의 도메인 집합 / Forest: 하나 이상의 Tree, AD 최상위 경계
  • Trust: 서로 다른 도메인의 사용자 인증과 자원 접근을 연결
  • Global Catalog: Forest 전체 객체의 일부 속성을 보관해 검색·로그온 지원
  • GPO: 사용자·컴퓨터 설정을 Site/Domain/OU에 일괄 적용
