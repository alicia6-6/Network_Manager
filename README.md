# 네트워크관리사 2급 기출문제 학습 사이트

정적 HTML/CSS/JS로 만든 기출문제 학습 사이트입니다. 빌드 과정 없이 GitHub Pages에 그대로 올려서 사용할 수 있습니다.

## 기능

- **랜덤 문제 풀기** (`quiz.html?mode=random`) — 전체 문제 중 한 문제씩 무작위 출제
- **빈출문제 풀기** (`quiz.html?mode=frequent`) — 여러 회차에서 동일/유사하게 반복 출제된 문제를 자동으로 모아서 출제 (`data/questions.json`의 문제 텍스트를 비교해 자동 계산)
- **차수별로 풀기** (`quiz.html?mode=round`) — 회차를 선택해 순서대로 풀이, 종료 시 점수/정답률 표시
- **오답노트** (`quiz.html?mode=wrong`) — 틀린 문제를 브라우저(localStorage)에 자동 저장, 맞히면 자동 제거
- **요약노트** (`summary.html`) — 시험 범위 핵심 개념 정리

## 폴더 구조

```
index.html          홈 (메뉴, 통계)
quiz.html            문제 풀이 화면 (mode 파라미터로 4가지 모드 분기)
summary.html         요약노트
css/style.css        공통 스타일 (라이트/다크 모드 자동 대응)
js/data.js           문제 데이터 로딩, 빈출문제 계산, 오답노트 저장 유틸
js/quiz.js           문제 풀이 화면 로직
data/questions.json  기출문제 데이터 (아래 스키마 참고)
```

## 문제 데이터 스키마 (`data/questions.json`)

```json
{
  "meta": { "examName": "네트워크관리사 2급", "updatedAt": "2026-08-11" },
  "questions": [
    {
      "id": "2023-1-01",
      "round": "2023년 1차",
      "number": 1,
      "subject": "TCP/IP",
      "question": "문제 지문",
      "choices": ["보기1", "보기2", "보기3", "보기4"],
      "answer": 2,
      "explanation": "정답 해설",
      "tags": ["서브네팅", "IP주소"]
    }
  ]
}
```

- `answer`는 1~4의 정답 보기 번호(①②③④ 기준)입니다.
- `round`는 "2023년 1차"처럼 표기하며, 차수별 풀기 화면의 드롭다운/필터에 그대로 사용됩니다.
- 빈출문제는 `question` 텍스트를 정규화(공백/기호 제거)해서 동일한 문제가 2회 이상 등장하면 자동으로 "빈출"로 분류합니다. 별도 태그를 붙일 필요가 없습니다.
- `image`는 문제에 캡처 화면/다이어그램이 딸려 있을 때 상대 경로(`data/images/<회차>/qNN.gif`)를 넣습니다. 없으면 `null`.

### 현재 데이터 현황

- 2023년 1차 ~ 2026년 2차, 총 14개 회차 · 700문제 (회차당 50문제)
- hwp 기출문제 원본(정답 표시만 있고 해설 없음)을 파싱해 문제/보기/정답/이미지를 추출하고, 해설은 AI가 직접 작성했습니다. 오탈자나 애매한 해설을 발견하면 알려주세요.
- 문제 중 8개는 원본이 벡터 도형(캡처 이미지가 아닌 그림 개체)이라 이미지 추출에 실패했습니다 — 문제/보기 텍스트만으로 해설을 작성해두었습니다.
- 2026년 3차(정기 제03회) 시험은 정답이 표시되지 않은 원본만 있어 이번 데이터에서 제외했습니다. 정답 공개 후 추가할 수 있습니다.
- hwp 원본은 상업 CBT 사이트(comcbt.com)의 저작물이라 `.gitignore`로 제외하고 로컬에만 보관합니다.

## 로컬에서 확인하기

정적 파일이라 아무 서버로나 띄우면 됩니다. 예:

```bash
python -m http.server 8000
# http://localhost:8000 접속
```

`fetch`로 JSON을 불러오기 때문에 `index.html`을 파일로 직접 더블클릭해서 열면 동작하지 않습니다(반드시 로컬 서버 경유).

## GitHub Pages 배포

1. GitHub에 새 저장소를 만들고 이 폴더 내용을 push
2. 저장소 Settings → Pages → Source를 `main` 브랜치 `/ (root)`로 설정
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 에서 접속 가능

별도 빌드 스텝이 없으므로 push만 하면 바로 반영됩니다.
