# 네트워크관리사 2급 기출문제 학습 사이트

정적 HTML/CSS/JS로 만든 기출문제 학습 사이트입니다. 빌드 과정 없이 GitHub Pages에 그대로 올려서 사용할 수 있습니다.

🔗 **사이트 바로가기**: https://alicia6-6.github.io/Network_Manager/index.html

## 기능

- **회차별 모의시험** (`quiz.html?mode=round`) — 회차를 골라 50분 타이머 + 문제 이동 맵으로 실전처럼 응시, 제출 후 점수·정답률·오답 리뷰 제공
- **랜덤 문제** (`quiz.html?mode=random`) — 전체 문제 중 한 문제씩 무작위로 가볍게 학습
- **빈출문제** (`quiz.html?mode=frequent`) — 여러 회차에서 동일하게 반복 출제된 문제를 자동으로 모아서 학습 (`data/questions.json`의 문제 텍스트를 비교해 자동 계산)
- **오답노트** (`quiz.html?mode=wrong`) — 틀린 문제를 브라우저(localStorage)에 자동 저장, 맞히면 자동 제거
- **요약노트** (`summary.html`) — 시험 범위 핵심 개념 정리
- **실기 기출문제** (`practical.html`) — 92회~109회 실기 기출의 IP/서브넷 문제(2번)와 단답형·선택형·라우터 문제(10~18번)를 정답·해설과 함께, 나머지 실습형(Windows Server GUI) 문제(3~9번)는 문제만 회차별로 확인

## 폴더 구조

```
index.html          홈 (메뉴, 통계)
quiz.html            문제 풀이 화면 (mode 파라미터로 4가지 모드 분기)
summary.html         요약노트
practical.html        실기 기출문제
css/style.css        공통 스타일 (라이트/다크 모드 자동 대응)
js/data.js           문제 데이터 로딩, 빈출문제 계산, 오답노트 저장 유틸
js/quiz.js           문제 풀이 화면 로직
js/practical.js      실기 기출문제 화면 로직 (회차 선택/렌더링)
data/questions.json  기출문제 데이터 (아래 스키마 참고)
data/practical.json  실기 기출문제 데이터 (아래 스키마 참고)
```

## 문제 데이터 스키마 (`data/questions.json`)

```json
{
  "meta": { "examName": "네트워크관리사 2급", "totalRounds": 15, "totalQuestions": 750 },
  "questions": [
    {
      "id": "2023-02-01",
      "round": "2023년 1차",
      "number": 1,
      "subject": "TCP/IP",
      "question": "문제 지문",
      "choices": ["보기1", "보기2", "보기3", "보기4"],
      "answer": 2,
      "explanation": "정답 해설",
      "image": null,
      "tags": []
    }
  ]
}
```

- `answer`는 1~4의 정답 보기 번호(①②③④ 기준)입니다.
- `round`는 "2023년 1차"처럼 표기하며, 회차별 모의시험 화면의 드롭다운/필터에 그대로 사용됩니다.
- 빈출문제는 `question` 텍스트를 정규화(공백/기호 제거)해서 동일한 문제가 2회 이상 등장하면 자동으로 "빈출"로 분류합니다. 별도 태그를 붙일 필요가 없습니다.
- `image`는 문제에 캡처 화면/다이어그램이 딸려 있을 때 상대 경로(`data/images/<회차>/qNN.png|gif`)를 넣습니다. 없으면 `null`.
- `subject`는 원본 문서의 "N과목" 구분표를 그대로 따른 것으로, TCP/IP(1~17번) · 네트워크 일반(18~27번) · NOS(28~45번, 윈도우서버/리눅스로 세분화) · 네트워크 운용기기(46~50번) 4과목 체계입니다.

### 현재 데이터 현황 (2026-08-11 기준)

- 2023년 1차 ~ 2026년 3차, 총 15개 회차 · 750문제 (회차당 50문제)
- hwp 기출문제 원본(정답 표시만 있고 해설 없음)을 파싱해 문제·보기·정답·이미지를 추출했습니다. 정답은 원본에 별도로 포함된 "가채점 답안" 표와 전량 교차검증해 700+50문제 모두 일치를 확인했습니다.
- 해설은 AI가 직접 작성했습니다. 중복 문제를 제거한 506개 고유 문제 전량을 별도 검토 과정에서 재검증해 4건의 오류(용어 설명 오류 등)를 찾아 수정했습니다.
- 문제 중 8개는 원본이 벡터 도형(캡처 이미지가 아닌 순수 그림 개체)이라 이미지 추출에 실패했습니다 — 문제/보기 텍스트만으로 해설을 작성해두었습니다.
- 2026년 3차(정기 제03회, 2026-08-02 시행)는 문항 안에 정답 표시가 없는 원본이었지만, 문서 끝의 "가채점 답안" 표에서 정답을 확인해 포함했습니다. 50문제 중 26문제는 이전 회차와 겹치지 않는 새 문제였습니다.
- hwp 원본은 상업 CBT 사이트(comcbt.com)의 저작물이라 `.gitignore`로 제외하고 로컬에만 보관합니다.

## 실기 기출문제 데이터 스키마 (`data/practical.json`)

리모트코리아·네트워크관리사연구소가 배포하는 "N회 네트워크관리사2급 실기 정답 및 해설" PDF(92회~109회, 2022년 1차~2026년 2차, 총 18개 회차)를 파싱해 만들었습니다. 실기 시험은 매 회차 18문항(1번 UTP케이블 실습 제외 17문항을 수록)으로 구성되며, 문항을 아래 4가지로 분류합니다.

```json
{
  "meta": { "examName": "네트워크관리사 2급 실기", "totalRoundsPlanned": 18, "roundsIncluded": 18 },
  "rounds": [
    {
      "round": "108회",
      "date": "2026-03-08",
      "ip": { "number": 2, "given": "210.100.10.0/24", "prompt": "...", "answer": "...", "explanation": "..." },
      "practice": [ { "number": 3, "category": "DHCP", "prompt": "..." } ],
      "written": [ { "number": 10, "type": "단답형", "prompt": "...", "answer": "...", "explanation": "..." } ],
      "router": [ { "number": 16, "topology": "...", "prompt": "...", "answer": "...", "explanation": "..." } ]
    }
  ]
}
```

- `ip` (2번, IP/서브넷 계산): 정답·해설 포함, 회차당 1개.
- `practice` (3~9번, DHCP/DNS/웹사이트/FTP사이트/로컬보안정책/로컬사용자 및 그룹/서비스관리자 등 Windows Server GUI 실습): 문제만 제공하고 정답은 수록하지 않음(실기 채점 특성상 텍스트 정답의 의미가 낮음).
- `written` (10~15번대, 단답형·선택형·드래그앤드롭형): 정답·해설 포함.
- `router` (16~18번, Cisco 라우터 CLI 문제): 정답·해설 포함, 다이어그램이 있는 경우 `topology`에 텍스트로 설명.

### 알려진 한계

- 원본 PDF는 실기 정답 해설(GUI 클릭 순서 포함)만 있고 개념 설명은 부족한 경우가 많아, 해설 문구는 AI가 원본 내용을 바탕으로 보강했습니다.
- 98회 문제12는 원본에 WAF·UTM 두 문항이 같은 번호로 함께 수록되어 있어 `written` 배열에 번호 12가 두 번 등장합니다.
- 103회·104회 등 일부 회차는 원본 PDF 자체가 "실제 출제 문제와 수치가 다를 수 있다"는 템플릿 예시로 표기되어 있어, 다른 회차와 값이 겹치는 경우가 있습니다(원본 표기 그대로 유지).
- 원본 PDF(리모트코리아·네트워크관리사연구소 저작물)는 `2026년_네트워크관리사_실기(수정)/` 폴더에 로컬로만 보관하며 `.gitignore`로 저장소에서 제외했습니다. 저장소/사이트에는 변환된 문제·정답 데이터만 포함됩니다.

## 로컬에서 확인하기

정적 파일이라 아무 서버로나 띄우면 됩니다. 예:

```bash
python -m http.server 8000
# http://localhost:8000 접속
```

`fetch`로 JSON을 불러오기 때문에 `index.html`을 파일로 직접 더블클릭해서 열면 동작하지 않습니다(반드시 로컬 서버 경유).

## GitHub Pages 배포

1. GitHub에 새 저장소를 만들고 이 폴더 내용을 push
2. 저장소 Settings → Pages → Source를 `main` 브랜치 `/ (root)`로 설정
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 에서 접속 가능

별도 빌드 스텝이 없으므로 push만 하면 바로 반영됩니다.
