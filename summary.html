PDU: 1계층=비트, 2계층=프레임, 3계층=패킷, 4계층=세그먼트(TCP)/데이터그램(UDP)

2. TCP/IP 기초

TCP vs UDP

구분TCPUDP
연결 방식연결지향형 (3-way handshake)비연결형
신뢰성높음 (재전송, 순서제어)낮음 (신뢰성 보장 안함)
흐름/혼잡 제어있음없음
속도상대적으로 느림빠름
사용 예웹(HTTP), 메일, 파일전송DNS 질의, 스트리밍, VoIP

3-way handshake

SYN → SYN+ACK → ACK 순서로 연결을 설정하며, 연결 종료 시에는 4-way handshake(FIN → ACK → FIN → ACK)를 사용합니다.

7. LAN·케이블·무선랜

  • UTP 케이블 카테고리: Cat5(100Mbps), Cat5e(1Gbps), Cat6(1~10Gbps), Cat6a/Cat7(10Gbps 이상)
  • 다이렉트 케이블: 서로 다른 장비 연결(PC-스위치) / 크로스 케이블: 같은 종류 장비 연결(PC-PC, 스위치-스위치)
  • 광케이블: 단일모드(장거리), 다중모드(단거리), 전자기 간섭 없음, 고속 전송
  • 무선랜 표준(IEEE 802.11): a/b/g/n/ac/ax 순으로 발전, 주파수 대역 2.4GHz·5GHz
  • CSMA/CD: 유선랜(이더넷)의 충돌 감지 방식 / CSMA/CA: 무선랜의 충돌 회피 방식

8. 네트워크 보안

  • 방화벽(Firewall): 정해진 규칙에 따라 패킷을 허용/차단, 내부망과 외부망 경계에 위치
  • IDS(침입탐지시스템): 공격을 탐지하고 알림만 수행 / IPS(침입방지시스템): 탐지 후 자동 차단까지 수행
  • VPN: 공중망을 통해 암호화된 사설 터널을 구성하여 안전하게 통신
  • DoS/DDoS: 서비스 거부 공격으로 다수의 트래픽을 발생시켜 정상 서비스를 방해
  • NAT: 사설 IP ↔ 공인 IP를 변환하여 내부 네트워크를 외부로부터 은닉, IP 주소 절약

9. 윈도우 서버 (NOS)

  • Active Directory(AD): 사용자·컴퓨터·그룹 등을 중앙에서 관리하는 디렉터리 서비스
  • DNS 서버 역할: 도메인 이름을 IP 주소로 변환, AD와 통합되어 도메인 컨트롤러 위치 확인에도 사용
  • DHCP 서버 역할: 클라이언트에게 IP 주소, 게이트웨이, DNS 등을 자동 할당(임대)
  • NTFS 권한: 파일/폴더 단위의 세밀한 접근 제어(ACL), 암호화(EFS), 압축 지원
  • 그룹 정책(GPO): 도메인 내 사용자·컴퓨터에 정책을 일괄 적용
